Назначение

JSON-шаблоны используются страницей «Импорт из JSON» на странице курса (кнопка у преподавателя: /courses//import/). Импорт создаёт уроки с материалами и домашние задания (в том числе из нескольких задач). Импорт транзакционный: при любой ошибке не сохраняется ни один объект, а страница показывает полный список проблем.

Верхний уровень документа

Допустимы две формы: объект с ключами lessons / homeworks или просто список уроков (массив объектов — эквивалент {"lessons": […]}).

Ключ Тип Описание
lessons список объектов Уроки курса. Порядок (order) продолжается после существующих уроков автоматически.
homeworks список объектов Домашние задания без привязки к уроку (также принимается ключ homework).

Объект «Урок» (lessons[])

Поле Обязательное Описание
title да Название урока (до 200 символов).
content нет Материалы урока — текст с поддержкой LaTeX ($…$, $$…$$).
homeworks нет Список ДЗ этого урока (объект или массив объектов; принимается и ключ homework).

Объект «Домашнее задание» (homeworks[])

Поле Тип Описание
title строка, обязательно Название ДЗ.
task строка Условие ДЗ (LaTeX поддерживается). Если есть problems — общий текст перед задачами.
answer_type строка Режим автопроверки: NONE (ручная), EXACT (точный ответ), NUMERIC (число с допуском), MULTIPLE (несколько ответов). Регистр не важен; по умолчанию NONE.
expected_answer строка Эталонный ответ для автопроверки (для MULTIPLE — ответы через \n или ;).
numeric_tolerance число Допуск для NUMERIC (по умолчанию 0).
require_photo true/false Ученик обязан приложить фото решения.
auto_issue true/false Автовыдача ДЗ после проведения связанного урока.
issued true/false Открыть ДЗ сразу (иначе скрыто до выдачи).
deadline строка-дата Срок сдачи: «2025-09-15» или «2025-09-15 18:00» (локальное время сайта).
problems список объектов Отдельные задачи ДЗ (см. ниже). Если задач нет — ДЗ проверяется как один ответ.

Объект «Задача» (problems[])

Поле Тип Описание
text строка Условие задачи (LaTeX поддерживается).
answer_type строка Те же режимы, что у ДЗ: NONE / EXACT / NUMERIC / MULTIPLE.
expected_answer строка Эталонный ответ задачи.
numeric_tolerance число Допуск для NUMERIC.
order число Порядковый номер задачи; по умолчанию — позиция в списке.

Формулы: корни, модули, дроби (LaTeX)

Поля content, task, text поддерживают LaTeX — формулы отображаются как в учебнике (движок KaTeX). Стройте в тексте между $…$ (встроенная формула), отдельные — между $$…$$ (выносная, по центру). В JSON обратный слэш удваивается: "\\sqrt{2}".

В JSON (текст поля) Как отобразится
Вычислите $\\sqrt{2}$. √2 — корень (в JSON: "$\\sqrt{2}$")
Решите $|x-1| = 3$. |x−1| = 3 — модуль (вертикальные черты пишутся как есть)
$\\frac{a^3}{a} = a^2$ обычная дробь, степени через ^, индексы через _
$$x = \\frac{-b \\pm \\sqrt{D}}{2a}$$ выносная формула (корень в числителе — крупно, по центру)
$x \\ge 0$, $a \\neq 0$, $\\pi \\approx 3.14$ сравнения ≠/≤/≥/π — стандартные LaTeX-команды

Те же формулы можно вставлять без ручной печати слэшей — кнопками «Формулы» над полами текста в формах создания/редактирования ДЗ, уроков и ответов.

Полный пример

Тот же пример доступен прямо на странице импорта (кнопка «Вставить пример»). 

{
  "lessons": [
    {
      "title": "Квадратные уравнения",
      "content": "Теорема Виета: $x_1 + x_2 = -b/a$. Разбор примеров на доске.",
      "homeworks": [
        {
          "title": "ДЗ 1. Квадратные уравнения",
          "task": "Решите уравнения. Оформите решение на фото.",
          "require_photo": true,
          "auto_issue": true,
          "deadline": "2025-09-20 18:00",
          "problems": [
            {
              "text": "Решите уравнение $x^2 - 5x + 6 = 0$. В ответе запишите оба корня, каждый с новой строки.",
              "answer_type": "MULTIPLE",
              "expected_answer": "2\n3"
            },
            {
              "text": "Найдите произведение корней уравнения $x^2 - 7x + 10 = 0$.",
              "answer_type": "NUMERIC",
              "expected_answer": "10",
              "numeric_tolerance": 0.01
            }
          ]
        }
      ]
    },
    {
      "title": "Неравенства",
      "content": "Метод интервалов.",
      "homeworks": [
        {
          "title": "ДЗ 2. Неравенства",
          "task": "Решите неравенство $(x-1)(x+4) < 0$.",
          "answer_type": "EXACT",
          "expected_answer": "(-1; 4)"
        }
      ]
    }
  ],
  "homeworks": [
    {
      "title": "Дополнительное задание",
      "task": "Упростите выражение $\\frac{a^3}{a}$ при $a \\neq 0$.",
      "answer_type": "EXACT",
      "expected_answer": "a^2"
    }
  ]
}

Правила и ограничения

  • Файл должен быть в кодировке UTF-8 (BOM допускается).
  • Изображения (task_image, image задач) через JSON не импортируются — только текст.
  • Пустой документ (без уроков и ДЗ) считается ошибкой — импорт не выполняется.
  • Ошибки валидации модели (например, слишком длинный title) показываются с указанием объекта: «Урок 2, ДЗ 1: …».
  • Доступ к импорту — только у владельца курса (преподавателя); к этой странице настроек — только у суперпользователя.
